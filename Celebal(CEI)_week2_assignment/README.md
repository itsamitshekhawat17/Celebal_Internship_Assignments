# Celebal (CEI) — Week 2 Assignment

## Overview
This folder contains the Week 2 deliverables for the Celebal (CEI) internship assignments. It includes a Jupyter notebook analysis and an SQL file for the second question.

## Contents
- `assignment2_first_ques.ipynb` — Jupyter notebook analyzing the Sample - Superstore dataset.
- `assignment2_second_ques.sql` — SQL queries for the second assignment question.
- `data/Sample - Superstore.csv` — Dataset used in the notebook.

## Setup
1. Create a virtual environment (recommended):

   python -m venv .venv
   .venv\Scripts\activate

2. Install dependencies:

   pip install -r requirements.txt

## Running
- To run the notebook: start Jupyter and open `assignment2_first_ques.ipynb`.

  jupyter notebook

- To run the SQL file: use your preferred SQL client (SQLite, MySQL, PostgreSQL). The file contains raw SQL queries to be executed against an appropriate dataset/table.

## Notes
- The notebook expects the CSV at `data/Sample - Superstore.csv`.
- If you need to reproduce SQL queries against a relational DB, import the CSV into a table with appropriate schema first.
